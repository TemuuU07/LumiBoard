Wo finde ich die IP?

Das OLED-Display am LumiBoard zeigt die IP direkt beim Einschalten an.

Ohne Display: Serial Monitor in VS Code öffnen.

Beispiel: 192.168.1.100

💡 Im Router eine feste IP vergeben — dann ändert sie sich nie.
⚠ Auf dem Handy bitte diese Seite über HTTP öffnen — sonst kann der Browser den ESP32 nicht erreichen.

Anleitung

So funktionierts

01
🔌
ESP32 einschalten
ESP32 verbindet sich automatisch mit dem WLAN. Beim ersten Mal öffnet er den Hotspot LumiBoard-Setup.
02
🖥
IP ablesen
Das OLED-Display zeigt die IP nach dem Start an. Ohne Display: Serial Monitor in VS Code öffnen.
03
⚙
IP eingeben
Oben rechts auf ⚙ klicken, IP eintippen — wird dauerhaft gespeichert.
04
🎮
Spielen
Spiel auswählen und losspielen — Snake/Pong/Tetris per Tastatur, MADN per Taster oder Website.
